# 🚀 Sattar Tasks – SaaS Landing Page Template

A modern, fast and responsive landing page built with **React**, **Tailwind CSS** and **Motion**.

## ✨ Features
- Fully responsive (mobile, tablet, desktop)
- Dark / light mode (remembers your choice)
- Smooth scroll animations
- Pricing table with monthly / yearly toggle
- FAQ accordion
- All text in ONE file: `src/data/content.js`

## 🛠️ Install
```bash
npm install
npm run dev
```
Open http://localhost:5173

## ✏️ Customize
1. Open `src/data/content.js`
2. Change the text between the quotes `" "`
3. Save. Done!

**Change the main color:** search for `indigo` in `src/components` and replace it with another Tailwind color (for example `emerald`, `rose`, `sky`).

## 🚀 Deploy
Push to GitHub, then import the repo on **Vercel** and click **Deploy**.
